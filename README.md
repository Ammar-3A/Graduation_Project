# TUMB — Taibah University Marketplace Bot

A rule-based conversational marketplace platform designed for the Taibah University community.

TUMB enables students and staff to buy, sell, compare, and manage second-hand academic supplies through a chatbot-driven interface.

The platform focuses on creating a trusted university-exclusive marketplace that simplifies peer-to-peer trading while promoting affordability and sustainability.

---

## Features

- User registration and authentication
- Rule-based chatbot interaction
- Create, edit, and delete marketplace posts
- Search for items by category or keyword
- Compare products directly inside the chat flow
- Personalized recommendations
- Report inappropriate listings
- Admin dashboard and moderation tools
- AI-powered extension using LLMs and MCP integration

## System Architecture

The system follows a client-server architecture:

- **Frontend** handles user interaction and chatbot UI
- **Backend** manages authentication, marketplace operations, and APIs
- **Database** stores users, posts, reports, and marketplace data
- **AI Agent Extension** enables advanced conversational reasoning and tool integration
